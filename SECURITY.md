# Security

Please report security issues in this project privately through GitHub's
[private vulnerability reporting](https://github.com/janpaepke/spielebox-mcp/security/advisories/new), not as a public issue.

Relevant are, for example, ways to send a reservation request without the user's confirmation, to reach the local confirmation
page from another site or machine, or to leak contact details.

This project is unofficial and not affiliated with WIENXTRA. Issues with the WIENXTRA website or catalog itself are out of scope;
please report those to WIENXTRA directly.
